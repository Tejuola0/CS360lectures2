# Introduction to Haskell Examples

These are the completed examples used in class. Start with `Examples.hs`.
`Demo.hs` replays the examples, and `Tests.hs` checks their behavior.

To explore the definitions interactively with the course version of GHC:

```console
ghci Examples.hs
```

To replay the demonstration or run the checks:

```console
make demo
make test
```
